# Scripts

Utility scripts used to operate and maintain the project.

Current state:
- enqueue_job.py: helper script to push jobs into the worker queue.
- export_openapi.py: helper script to export the backend's OpenAPI spec.

How to use:
- Run scripts directly with the project environment active, e.g. `python scripts/export_openapi.py`.
- Add any required environment variables or configuration details to each script's header.
